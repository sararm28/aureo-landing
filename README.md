# Aureo — Landing page de joyería

Página de presentación para **Aureo**, una marca ficticia de joyería femenina. Muestra colecciones de collares, aretes, pulseras y anillos, una sección "Nosotros" y un formulario de contacto.

## Objetivo
Diseñar una landing page atractiva y adaptable a celulares que presente los productos de una marca y facilite que los clientes la contacten.

## Tecnologías
- HTML5 (estructura semántica)
- CSS3 (Flexbox, Grid, variables, diseño responsive)
- JavaScript (menú móvil, filtro de productos, contadores animados y validación del formulario)

## Funcionalidades
- Menú tipo hamburguesa en pantallas pequeñas.
- Filtro de productos por categoría.
- Contadores animados en la sección "Nosotros".
- Formulario de contacto validado con JavaScript.

## Mi aporte
Desarrollé el proyecto de forma individual: la estructura en HTML, los estilos en CSS y las funciones en JavaScript. Elegí la paleta de colores y las fuentes para transmitir una imagen elegante.

## Aprendizaje
Aprendí a organizar una página por secciones, a usar Flexbox y Grid para que se vea bien en celular y en computador, y a manipular el DOM con JavaScript. Como mejora, me gustaría conectar el formulario a un servicio de correo real.

## Cómo verlo
Abre `index.html` en el navegador o visita la versión publicada en GitHub Pages.
